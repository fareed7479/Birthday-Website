# Birthday Website

Pages: Lock (PIN 2705) > Countdown > Greeting > Yes/No > Balloons > Chocolate cake > Photos > Compliments > Letter > Promises > Gift.

## Personalise
Open `config.js` and change her name, your name, hint, letter, captions, promises and balloon words.
Put 4 photos in `photos/` named `1.jpg` to `4.jpg`.

## Run
Double-click `index.html`. For the microphone (blow the candles) the site must be served over https, which the hosts below do for you.

## Put it online (free)
- Netlify: go to app.netlify.com/drop and drag this whole folder in.
- Or GitHub Pages: upload the folder to a repository and enable Pages.

## Notes
- The girl-sticker cursor only shows on computers; phones have no cursor.
- Stickers live in `assets/`, colours and layout in `style.css`.
- The music button plays a built-in music-box tune, no audio file needed.
